集成学习与对抗知识蒸馏实现轻量化焊接状态监测

An efficient welding state monitoring model for robotic welding based on ensemble learning and generative adversarial knowledge distillation

2025 Measurement, 242, 116096

Runquan Xiao; Kanghong Zhu; Qiang Liu; Huabin Chen; Shanben Chen

研究问题

多个深度网络联合判断可以提高焊接状态识别能力，但计算开销过大时，怎样兼顾准确性和在线速度？

研究方法

构建基于 D-S 证据理论的多模型决策框架，并利用生成对抗式知识蒸馏将多个教师网络的特征与决策知识转移到单个学生网络。部署时只运行压缩后的模型，减少多模型并行推理的开销。

主要结果

在论文的机器人 GTAW 状态识别测试中，模型准确率为 95.7%，所用平台的平均处理时间为 24.2 ms。研究展示了把多模型监测知识压缩到单模型的实现路线。

DOI: 10.1016/j.measurement.2024.116096 ↗
