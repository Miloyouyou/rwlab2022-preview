An efficient welding state monitoring model for robotic welding based on ensemble learning and generative adversarial knowledge distillation

2025 Measurement, 242, 116096

Runquan Xiao; Kanghong Zhu; Qiang Liu; Huabin Chen; Shanben Chen

Research question

How can welding-state monitoring retain the benefits of an ensemble without running several large networks online?

Method

A Dempster–Shafer ensemble framework is combined with adversarial knowledge distillation to transfer multiple teachers' features and decisions to one student network. Online deployment uses the student rather than running the full ensemble.

Main findings

In the reported robotic GTAW classification tests, the model achieved 95.7% accuracy with an average processing time of 24.2 ms on the experimental platform. The work demonstrates a route from multi-model monitoring knowledge to single-model inference.
